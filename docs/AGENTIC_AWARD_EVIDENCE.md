# Agentic Vision Award Evidence Map

This document maps the official special-award rubric to executable evidence. It is a navigation aid, not a self-awarded score. Judges should use the linked artifacts, API trace, and live demonstration.

## 1. Substantive OpenCV 5 and agent integration — 30%

- OpenCV 5 DNN loads the ONNX backbone and produces PatchCore feature maps and anomaly scores (`core/perception.py`).
- OpenCV ORB/RANSAC and ECC perform reference recovery; OpenCV photometric comparison, contour extraction, and rotated rectangles produce secondary evidence (`core/tools.py`).
- The policy uses that evidence to change later decisions: ambiguous scores may become `AGENT_CLEARED`, `AGENT_CONFIRMED`, `INCONCLUSIVE`, `ALIGN_FAILED`, or `SUSPECTED_DEFECT` (`core/agent.py`).
- Runtime proof is generated by `python -m eval.verify_opencv5_runtime` into `eval/results/opencv5_runtime_proof.json`.
- The ten-path evidence matrix is generated by `python -m eval.generate_agentic_evidence`.

## 2. Orchestration and appropriate autonomy — 25%

- Perception proposes candidate regions; the controller conditionally calls alignment, comparison, next-ROI inspection, lighting normalization, and measurement.
- Tool work is bounded by four evidence steps and a latency ceiling. Unchecked candidates or exhausted budgets route to `HUMAN`.
- OpenCV-measured scale now changes the clearance policy. A strongly resampled frame may be geometrically recovered, but automatic clearance uses a stricter score margin to account for lost fine detail.
- Every response includes a structured `next_action`: `CONTINUE_LINE`, `QUARANTINE_PENDING_CONFIRMATION`, `REVIEW_EVIDENCE`, or `REQUEST_RETAKE`.
- All actions are `recommendation_only`; the API explicitly records that no external actuator was triggered.

## 3. Task effectiveness and evaluation — 20%

- The measured E1 regression uses 493 real Amazon VisA PCB images and keeps `PASS`, `FAIL`, `HUMAN`, and `RETAKE` separate.
- `eval/run_real_e1.py` fingerprints inference code, model/bank/calibration artifacts, and templates. Dirty inference changes therefore invalidate stale prediction caches.
- `python -m eval.run_acquisition_robustness` runs 15 real-engine acquisition cases covering exact sample routing, exact uploaded bytes, PNG round trips, 0.729× browser resizing, and JPEG quality 90.
- Assertions prohibit known-bad transformed samples from escaping as `PASS`, prohibit automatic `FAIL` for the known-good sample, verify exact-route parity, and enforce the tool budget.
- `docs/INDEPENDENT_FINAL_EVALUATION_PROTOCOL.md` clearly separates the current previously seen regression split from a future genuinely independent evaluation.

## 4. Failure handling, observability, security, and human control — 15%

- Admission failures return `RETAKE` before anomaly inference.
- Alignment failure, evidence conflict, lighting shift, incomplete ROI coverage, and budget exhaustion abstain to a human.
- The downloadable trace records tool, reason, status, budget accounting, duration, and overlays.
- Session ownership prevents cross-session access to traces and assets; upload limits and bounded retention reduce exposure.
- Feedback is audit-only and never silently changes the production model or thresholds.
- Automated `FAIL` recommends reversible quarantine and requires operator confirmation.

## 5. User experience, documentation, and demonstration — 10%

- The operator UI exposes the official decision, thresholds, calibration assumptions, measured scale/overlap, evidence trace, counterfactual alpha settings, and structured next action.
- Mobile camera capture supports rear/front camera selection and uploaded-file fallback.
- `DEMO_SCRIPT.md` and `docs/VIDEO_SHOT_LIST.md` define the five-minute evidence sequence.
- `python -m eval.verify_project` is the local judge command for tests, artifact integrity, split checks, OpenCV proof, agentic path coverage, acquisition robustness, API drift, and frontend verification.

## Competitive positioning from public entries

Public Agentic Vision entries commonly emphasize asking for another view, zooming, human approval, or issuing a work order. SureInspect should demonstrate the same perceive–decide–act pattern without pretending to control real factory hardware: OpenCV evidence changes the inspection plan and produces an explicit, reversible operator action with a complete trace. The differentiator is the combination of real VisA evaluation, conformal thresholds, deterministic safety paths, acquisition-shift recovery, and evidence receipts.

Examples reviewed: [InspectAgent](https://devpost.com/software/inspectagent), [InspectLoop](https://devpost.com/software/inspectloop), [Guetteur](https://devpost.com/software/guetteur), and the [OpenCV AI Competition 2026 rules](https://opencv26.devpost.com/rules).

## Evidence still requiring a human owner

- Deploy the meaningful inference workload on AWS and capture the region/runtime proof.
- Record and publish the final video (five minutes or less).
- Run the frozen candidate once on genuinely independent, previously unseen data if available.
- Confirm team eligibility, licenses, and media rights before submission.

No repository change can honestly substitute for those external submission artifacts.
